# Sternenhimmel

Ein Theme für Claude in der Desktop- und Handy-App: ein dunkler, violetter Nachthimmel mit funkelnden Sternen, einer lila Milchstraße, zwei langsam drehenden Spiralgalaxien und gelegentlichen Sternschnuppen. Die Oberfläche bekommt passende Farben in Nachtviolett und Lavendel. Wer in den Systemeinstellungen „Bewegung reduzieren“ eingeschaltet hat, sieht den Himmel still.

## Installieren

In einer Claude-Code-Sitzung im Terminal:

```
/plugin install sternenhimmel --marketplace aaronwalkembach-lab/sternenhimmel-theme
```

Die Frage `Add marketplace?` mit `y` bestätigen und dann den Bereich (z. B. user) mit Enter wählen.

Aus einer Shell:

```bash
claude plugin install sternenhimmel --marketplace aaronwalkembach-lab/sternenhimmel-theme
```

In der Desktop-App: auf **+** neben dem Eingabefeld klicken, dann **Plugins**, **Add marketplace** mit `aaronwalkembach-lab/sternenhimmel-theme`, dann **Add plugin**.

Das Repository ist privat: Die Installation klappt nur mit einem GitHub-Konto, das das Repository lesen darf und auf dem Gerät bei GitHub angemeldet ist (z. B. `gh auth login` und danach `gh auth setup-git`).
